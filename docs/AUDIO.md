# ASHIGARU audio overhaul

All sound is generated by `tools/synth_audio.py` (numpy/scipy). **No recordings, sample libraries or Sonniss material were used** — see "Sources and licenses" for why. Result: 107 sound files (about 14 MB, 195 s), a rewritten audio service, positional gunfire, staged reload sounds tied to the real reload timer, surface-aware footsteps, layered palace ambience, menu/match audio and three volume sliders. Gameplay values, hit detection, movement, animation, AI and map are untouched.

## What changed

| Area | Implementation |
|---|---|
| Service | `scripts/sound_bank.gd` (`SoundBank`, same node/name as before): catalogue, voice pools (28 positional + 10 non-positional), per-category voice caps with priorities, delayed sounds on the *game* clock, event log for tests, bus setup. |
| Buses | Created at runtime: `Master` (hard limiter, ceiling −1 dB) → `SFX` (compressor + dynamic room reverb), `Ambient` (low-pass that closes indoors), `UI` (follows the SFX slider). |
| Musket | `musket_shot` ×3 (flint click + pan flash + crack, blast and sub-boom, outdoor tail), `musket_shot_far` ×2 (dull thud + rolling echo), dry-fire click, "not ready" click, raise/lower. |
| Reload | Six cues (lock click, powder, ramrod in, tamp, prime, cock) at 0 / 10 / 32 / 56 / 78 / 93 % of `Musket.RELOAD_TIME`, computed from `Musket.remaining`. They fire once each in order, restart with a new `Musket` (respawn), and are never driven by their own timer. With the katana out only a soft final cock is heard and any ramrod sound in progress is faded out in 80 ms. |
| Katana | Draw/raise on switch; full whoosh on a miss; shorter whoosh + flesh hit on a connect; surface clank (wood/stone/soil) when striking scenery; hit/kill confirmation ticks. Outcome is read from the existing trace result — no change to hit detection. |
| Impacts | Bullet impacts for wood, stone, soil and flesh at the real hit point, delayed by distance/343 m/s beyond 14 m. Surface from `Arena.surface_at`. |
| Gunfire distance | Own shot: clear non-positional. Others: <28 m close report; 28–70 m close report fading + delayed far report; >70 m far report only. 3D attenuation, per-sound unit size and max distance. |
| Footsteps | `scripts/footstep_emitter.gd`: stride length from *measured* ground speed (walk 1.8 m, sprint 2.15 m, crouch 1.25 m), ≥0.2 s between steps, landing sounds from fall speed, crouch cloth sound, teleport guard. Used by player and every bot (bots previously made no footstep sound). |
| Character | Pain ×3, death ×2 + body fall, respawn cue. Synthesised formant voice. A death cry fades any pain voice from the same actor. |
| Ambience | `scripts/ambience.gd`: wind, foliage, courtyard air and room-tone loops (seamless by construction) blended by player location (palace interior / garden / courtyard); positional birds, wood creaks (also occasionally under footsteps on wood), wind gusts. Indoors the Ambient low-pass closes and reverb room size/wet rise. |
| UI / match | Hover, click, confirm, back, slider tick, pause, match-start taiko + gong, victory / defeat / draw stingers, hit / headshot / kill confirmations. No match countdown exists in the game, so none was added. |
| Settings | Master, Effects, Ambience sliders (no music exists, so no music slider). Saved in `user://settings.cfg` keys `audio/master`, `audio/sfx`, `audio/ambient`; an old single `audio/volume` becomes master. |
| Lifecycle | `reset_world()` stops world voices and cancels delayed sounds on match start and return to menu; voices stop on tree exit. |

Modified gameplay scripts only gained audio calls: `weapon_controller.gd`, `player_controller.gd`, `bot_controller.gd`, `game.gd`, `main_menu.gd`. Damage, reload time, cooldowns, movement, AI and scoring lines are unchanged (the existing 50-check regression suite still passes).

## Validation (what was actually run)

* `tools/test_audio.sh` → `tests/audio.gd`: **85 checks, 0 failures** against the real game at 1× speed (the audio mixer follows the wall clock, so voice lifetimes are only meaningful in real time). Covers: all 107 files load; buses/limiter; wood/stone/soil sample brightness differs; slider → bus dB, mute, persistence, legacy file; menu and match sounds; player shot is clear/non-positional; **reload cues once each, in order, at 0.0/0.5/1.6/2.8/3.9/4.65 s, reload still 5.0 s**; switching to katana mid-reload keeps the reload and stays quiet; katana hit vs miss vs wall give different sounds; bot gunfire positional at the muzzle at near/mid/far ranges; bullet impacts by surface; footstep cadence 5 / 7 / 9 steps per 3 s for crouch / walk / sprint, none closer than 0.2 s, none when standing; surface selection; landing; pain/death/respawn; kill/headshot/hit confirmation; voice caps under an 80-shot barrage; garden vs palace vs courtyard ambience weights, filter and reverb; birds/creaks positional on the Ambient bus; menu return cancels delayed and playing sounds; four result stingers; **a complete 5v5 quick match (10 actors, ~86 s game time, 10–9)** with 27 shots, 18 reloads, 1,200 footsteps, 19 deaths, peak 28 of 38 voices, no missing resources.
* `tools/test.sh` (existing integration suite): 50 checks, 0 failures, 2 skipped (mouse capture needs a display), unchanged behaviour.
* Gameplay capture with the mixed audio recorded by Godot's movie writer (`tests/audio_capture.gd`): `dist/ASHIGARU-Audio-Demo.mp4`. Level measurements of the recorded mix are in the final section.
* Windows export: see "Build" below.

## Limitations (honest)

* **Nobody listened to this.** The environment has no speakers. Sound quality was judged by measurement (levels, spectra, balance), by event logs from running the real game, and by level-checking the recorded mix, not by ears. Expect to retune balance by ear.
* Synthesised sound is not a recording. Gunshots, steps and clanks are plausible but will not match professional field recordings; the **voice (pain/death) is a formant synthesiser and sounds artificial**. Replacing these ~10 files with licensed recordings is the biggest single quality upgrade; the catalogue in `sound_bank.gd` makes that a file swap.
* "Distant combat" is the real bots' gunfire via the far samples; no fake background battle was added.
* Reverb is a single dynamic bus effect (outdoor vs palace), not per-room acoustics. Indoor/outdoor uses the existing district rectangles and `surface_at`, so open wooden pavilions count as 35 % indoors.
* Bullet-by-bullet whizz/crack for near misses was not added.
* Windows build was exported and its package contents verified, but not run natively; the Linux export was smoke-tested with a full match.
* Headless tests run with the Dummy audio driver: they prove events, routing, voice behaviour and levels in the mix path, not that a particular speaker output is pleasant.

## Build

* Windows and Linux exports were produced with Godot 4.6.3 export templates. The Windows executable was scanned: all 107 imported audio streams and `sound_bank.gd`, `ambience.gd`, `footstep_emitter.gd` are inside the package.
* The Linux export ran a complete 5v5 match under a virtual display with the Dummy audio driver ("EXPORTED MATCH SMOKE: PASS"). The Windows build was not run natively.
* `dist/SamuraiWithMuskets-Windows.zip` / `-Linux.zip` hold the executable, PLAY.txt, licenses and these audio notes; checksums are in `dist/SHA256SUMS.txt`.
